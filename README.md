# Dan Linux 2.0

интерактивный сайт Дана о Linux и Open Source. обновление существующего [dan-linux](https://t3ns4ki.github.io/dan-linux/), а не отдельная замена проекта.

## что добавлено

- Linux Academy: 4 курса, 26 уроков, объяснения, примеры, практика, мини-тесты с разбором ошибок, XP, уровни и 7 достижений.
- общая безопасная песочница терминала: виртуальные файлы, права, переменные, пайпы, компиляция и пакеты. реальные команды никогда не запускаются. справка, ошибки и ответы переключаются кнопкой RU/EN вместе с сайтом; echo и содержимое файлов сохраняются буквально.
- генератор команд для 14 дистрибутивов, 7 операций, yay/paru и разных выпусков openSUSE. проверка ввода, объяснения, копирование и предупреждения.
- общественное голосование: 7 категорий, поиск, семейства, рейтинг и диаграмма настоящих голосов Supabase, изменение и отзыв голоса.
- приватные аккаунты Supabase Auth: почта, подтверждение, восстановление, опциональные Google/GitHub, профиль, экспорт данных, синхронизация и удаление.
- DanLinux Share: райсы, вопросы, обсуждения, изображения и комментарии с серверной модерацией; owner/admin по Auth UUID. [правила и назначение владельца](docs/SHARE.md).
- настройки на главной и в Share: свитч светлой/тёмной темы, кнопка RU/EN в шапке, русский/English, автоматический выбор по стране IP с резервом на язык браузера. [подробности](docs/SETTINGS.md).
- вращающаяся ASCII-трапеция: `chocolate-trapezoid` или `chocolate trapezoid` в терминале.

сохранены исходные разделы, авторский топ-5, каталог, альтернативы, подбор дистрибутива, мифы, тема, цветовые акценты и пасхалки. исправлена прежняя неподтверждённая фраза об открытом коде Windows Notepad.

## ещё немного Linux

- название вкладки — **OpenSource and Linux**.
- Ctrl+K / Cmd+K или кнопка поиска: разделы, дистрибутивы, уроки и команды. ↑/↓ выбирают, Enter открывает, Escape закрывает.
- Linux-лаборатория: калькулятор обычных девяти бит прав, примеры 644/755/600, символьная запись, копирование и вставка команды в симулятор. настройки сохраняются локально.
- задание дня: урок меняется по местной календарной дате браузера. если нужны предыдущие уроки, кнопка начинает с первого непройденного. статус опирается только на настоящий прогресс Academy; отдельные XP не начисляются.
- `sl`: ASCII-поезд Tux Express с паузой и повтором. `fortune`: случайная шутка или совет. анимация не запускается при prefers-reduced-motion; в скрытой вкладке поезд останавливается.

всё работает локально, без новых библиотек и запросов к платным API. GPL-3.0-or-later сохранена.

## быстрый запуск

распакуй исходники и открой терминал в каталоге с `index.html`:

```bash
python3 -m http.server 8000
```

открой <http://localhost:8000/>. остановка сервера — Ctrl+C. сборка и Node.js для обычной работы сайта не нужны. запуск через `file://` не рекомендуется: браузеры ограничивают сохранение, загрузку и Auth.

в этой версии подключён реальный проект Supabase `dan-linux` (`xrytmooypzycvrzuatdg`): применены схема и обе миграции, создан приватный Storage, развёрнута функция удаления. в `config.js` находится только настоящий публичный Publishable Key. фиктивных пользователей, голосов и постов нет. owner ещё не назначен: нужен UUID твоего подтверждённого аккаунта.

перед приглашением друзей проверь Auth URL Configuration и настрой SMTP по [инструкции](docs/SUPABASE.md). Google/GitHub OAuth пока выключены. доставка писем и полный вход с настоящим аккаунтом пока не проверены. без сервиса основные материалы и гостевое обучение продолжают работать.

## подключение и публикация

1. следуй [полной инструкции Supabase](docs/SUPABASE.md): SQL → Auth → публичная конфигурация → функция удаления → проверка.
2. опубликуй эти файлы в **существующем** репозитории `t3ns4ki/dan-linux` по [инструкции GitHub Pages](docs/DEPLOY.md).
3. исходный адрес останется `https://t3ns4ki.github.io/dan-linux/`, пока не изменены никнейм, репозиторий или Custom domain.

никогда не клади service_role, secret key, OAuth client secret, пароли или токены в `config.js`, HTML и Git. клиенту нужен только Supabase **Publishable Key** с префиксом `sb_publishable_`.

## разработка и проверка

нужен Node.js 22+ и Python 3 для упаковки. единственная npm-зависимость используется только в тестах: PGlite запускает настоящий PostgreSQL с RLS локально, без внешней базы.

```bash
npm ci
npm run build
npm run check
npm test
python3 scripts/package-source.py
```

`build` обновляет вставку новых разделов, CSP-хеш и серверный каталог из тех же уроков, что использует браузер. после изменения уроков недостаточно менять только клиент: подготовь отдельную SQL-миграцию с обновлением `revision` и серверных ответов. первоначальный `schema.sql` применяется **один раз к новому проекту**, а не поверх рабочей базы.

проверки и границы проверки описаны в [TESTING.md](docs/TESTING.md), модель безопасности — в [SECURITY.md](docs/SECURITY.md). `npm run check` не заменяет проверку секретов в твоём Git-истории.

## устройство проекта

| файлы | назначение |
| --- | --- |
| `index.html`, `style.css`, `app.js`, `data.js`, `assets/` | исходная страница, оформление и функции; добавлены точки интеграции |
| `config.js` | только публичные настройки реального Supabase-проекта |
| `v2/core.js`, `academy-data.js`, `academy-ui.js` | курсы, прогресс и интерфейс Academy |
| `v2/simulator.js`, `platform.js` | изолированная оболочка и соединение с прежним терминалом |
| `v2/commands.js`, `generator-ui.js` | проверяемая генерация команд |
| `v2/community-data.js`, `community-ui.js` | кандидаты, фильтры и настоящие результаты |
| `v2/backend.js`, `profile-ui.js`, `platform.css` | Auth, приватный профиль и адаптивные стили |
| `share/`, `v2/share-context.js` | лента, публикации, роли и модерация |
| `v2/settings.js`, `settings.css`, `english*.js` | тема, язык, автоопределение и локальные переводы |
| `supabase/schema.sql`, `supabase/functions/delete-account/` | PostgreSQL, RLS, RPC и удаление аккаунта |
| `scripts/`, `tests/`, `docs/`, `vendor/` | подготовка, проверки, инструкции и локальный SDK |

интерфейс не использует React или тяжёлый фреймворк. Supabase SDK 2.119.2 хранится локально и загружается только при настроенном сервисе. все шрифты и логотипы локальные. новые интерфейсы работают с клавиатуры, учитывают `prefers-reduced-motion`; анимация трапеции приостанавливается вне экрана и в скрытой вкладке.
